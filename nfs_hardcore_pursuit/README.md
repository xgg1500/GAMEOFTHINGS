## 🕹️ Oyun Kontrolleri
- **W / Yukarı Ok:** Gaz (İleri)
- **S / Aşağı Ok:** Fren & Geri Vites
- **A / D (Sol / Sağ):** Direksiyon & Dönüş
- **Shift:** Nitro Roket İtişi (Nitro Boost)
- **Boşluk (Space):** El Freni & Pacejka Gerçekçi Drift
- **C:** Kamera Açısı Değiştirme (3. Şahıs / Gerçekçi Kokpit)
- **0 Tuşu:** Acil Durum Heat Seviyesi Atlama
- **R:** Aracı Sıfırlama / Yeniden Başlatma

## 💻 Yerel Olarak Çalıştırma (Kendi Bilgisayarınızda)
1. Bu depoyu indirin veya klonlayın.
2. Klasörün içindeki `index.html` (veya `play_game.html`) dosyasını çift tıklayarak herhangi bir modern tarayıcıda (Chrome, Edge, Safari, Brave vb.) açın.
3. Veya yerel sunucu ile çalıştırmak isterseniz:
   ```bash
   npx serve .
   # veya
   python3 -m http.server 8000
   ```
